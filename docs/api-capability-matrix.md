# Simplia API capability matrix (frontend view)

Status: **Phase 1 draft**. Verified against `simpliadz-platform` source (endpoints, contracts,
validators, services) on 2026-11-20. Where backend docs and source disagree, **source wins**; see
[Backend doc discrepancies](#backend-doc-discrepancies).

"Screen" columns are the **proposed** frontend owners (not yet implemented).
Status legend: **Complete** = fully usable over HTTP · **Partial** = usable, but notable operations
are missing · **Unavailable** = no HTTP surface; no UI may be built.

## Cross-cutting contract facts

| Topic          | Fact                                                                                                                                                                                                                     | Frontend consequence                                                                                      |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------- |
| Base path      | Backend maps routes at root (`/auth/login`, `/products`), no `/api` prefix.                                                                                                                                              | Browser calls `/api/...`; dev proxy strips `/api`. Production reverse proxy **must** do the same rewrite. |
| CORS           | Not configured.                                                                                                                                                                                                          | SPA must be same-origin with the API (proxy). Document for production.                                    |
| Tenancy        | One active tenant per API process (`Tenancy:ActiveTenantId`). JWT carries `tenant_id`; mismatch → 401. No tenant header (`X-Tenant-Id` unsupported).                                                                     | Never send a tenant header. No tenant picker.                                                             |
| Module gating  | Disabled module → **404 empty body**, before auth.                                                                                                                                                                       | Treat a 404 on a list endpoint as "module unavailable", not "no data".                                    |
| AuthZ          | Policy per permission string (claim `permission`). 401/403 bodies are empty.                                                                                                                                             | UI checks are cosmetic; always handle 403.                                                                |
| Error format A | Global handler: `{error, message}`; validation `{error:"ValidationError", errors:[{propertyName (PascalCase), errorMessage}]}`; 404 `NotFound`; 409 `Conflict`/`InsufficientStock`; 400 `BadRequest`; 500 `ServerError`. | Normalize into one `ApiError`; map PascalCase property → camelCase form control.                          |
| Error format B | Sales/Purchasing/Accounting/Reporting/Audit/Stock/Work sessions: `application/problem+json` `{title,status,errors:{key:[msg]}}` (keys may be non-field: `pagination`, `dateRange`, `lines`…).                            | Same normalizer handles both shapes.                                                                      |
| Audit gate     | `RequireAudit()` → 409 `{"message":"Audit must be enabled for this action."}` (lower-case `message`, no `error`).                                                                                                        | Normalizer must read `message` without `error`.                                                           |
| Paging         | Catalog, identity lists: **unpaged full arrays**. Most other lists: `page` (1), `pageSize` (50, max 100), **plain array, no total**. Totals only on `/audit/entries`, `/reports/low-stock`, `/reports/inventory`.        | Client-side search/sort/paginate for catalog. "Load more"/next-page-if-full for paged arrays.             |
| Concurrency    | No ETag/rowversion in DTOs; last write wins across users.                                                                                                                                                                | Re-fetch after save; show 409 "changed concurrently" message when returned.                               |
| Deletion       | No hard delete (except removing role permissions / user roles). Deactivate only; **no reactivate** except users.                                                                                                         | Never show "Delete". Confirm deactivation as irreversible from UI.                                        |
| Enums          | DTO enums are strings; raw-entity endpoints (document/label templates) return numbers.                                                                                                                                   | Map per endpoint.                                                                                         |
| Local dev      | `http://localhost:5278`; Swagger at `/swagger` (Development only). Admin `admin@dev.local` / `Admin123!` (seeded by migrator).                                                                                           | e2e/local docs.                                                                                           |

## Identity — authentication (`Endpoints/Identity/AuthEndpoints.cs`)

| Endpoint                     | Permission    | Request                                          | Response                                                                                                       | Rules                                                                                                        | Screen             | Status                         |
| ---------------------------- | ------------- | ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ | ------------------ | ------------------------------ |
| `POST /auth/login`           | anonymous     | `email` (≤256, email), `password` (≤128)         | `accessToken, expiresMinutes, accessTokenExpiresAtUtc, refreshToken, refreshTokenExpiresAtUtc, email, roles[]` | Same 401 message for bad creds / inactive / locked. Lockout 5 attempts → 15 min. No permissions in response. | Login              | Complete                       |
| `POST /auth/refresh`         | anonymous     | `refreshToken` (≤512)                            | `LoginResponse`                                                                                                | Rotates every call; reuse of a rotated token revokes all user tokens. Concurrent double refresh → loser 401. | (interceptor)      | Complete                       |
| `POST /auth/logout`          | anonymous     | `refreshToken`                                   | 204 (idempotent)                                                                                               |                                                                                                              | User menu          | Complete                       |
| `GET /auth/me`               | authenticated | –                                                | `userId, email, roles[], permissions[], languageCode`                                                          | Reflects token claims and the saved language; no tenant.                                                     | Session bootstrap  | Complete                       |
| `PUT /auth/me/language`      | authenticated | `{ languageCode: "en" | "fr" | "ar" }`             | `{ languageCode }`                                                                                              | Persists the signed-in user’s display-language preference.                                                   | Account › Profile  | Complete                       |
| `POST /auth/change-password` | authenticated | `currentPassword` (≤128), `newPassword` (8–128)  | 204                                                                                                            | Invalidates sessions (security stamp) → user must sign in again. Wrong current pwd → 400 BadRequest.         | Account › Security | Complete                       |
| `POST /auth/forgot-password` | anonymous     | `email`                                          | `{resetToken}`                                                                                                 | Token only exposed in Development; otherwise `""`. No email is sent (Notifications is a stub).               | Forgot password    | Complete (dev-only usefulness) |
| `POST /auth/reset-password`  | anonymous     | `email, resetToken (≤4096), newPassword (8–128)` | 204                                                                                                            | 400 "Invalid reset request."                                                                                 | Reset password     | Complete                       |

Password policy: ≥8 chars, digit, lowercase, uppercase, non-alphanumeric. Session invalidation also on
user (de)activation, role assign/remove, and permission changes on the user's roles.
**Not available:** self-registration, email confirmation, MFA, invitations, external login.

## Backend doc discrepancies

1. `src/tenants.json` has `ActiveTenantId: "lokmane"`; all docs say `dev`.
2. Validation error body is `{error:"ValidationError", errors:[{propertyName, errorMessage}]}` (docs show `{Errors}`).
3. Product/location docs say there is no stock workflow; `/stock/*` exists.
4. Audit-module requirement (409) undocumented for price set, variant identifier edit, stock adjustments, count completion, goods receipts, cash sessions, sale cancel, user deactivate.
5. `PRODUCT_VARIANTS.md` doesn't say `attributeValueIds` must be non-empty.
6. `ORGANIZATION_MODULE.md` omits `timeZoneId` and the 404-on-fresh-tenant behaviour.
7. Duplicate user email / role name return 400, not 409.
8. No doc mentions missing CORS, unpaged array lists, or the two error formats.
